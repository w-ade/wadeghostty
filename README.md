# Liquid Glass

<img src="preview-ghostty.jpg" width="680" alt="Liquid Glass Dark in Ghostty">

Translucent dark terminal theme for macOS — **Terminal.app** and **Ghostty**. The Terminal
profile is generated by a JXA script, so the palette lives in source, not a binary plist.

## Install

**Terminal.app** — `open "Liquid Glass Dark.terminal"`, then **Settings → Profiles →
Default**.

**Ghostty:**

```sh
mkdir -p ~/.config/ghostty/themes
cp ghostty/liquid-glass-dark ~/.config/ghostty/themes/
```

Set `theme = liquid-glass-dark` in `~/.config/ghostty/config`. Don't also set
`background-opacity` or `background-blur-radius` there — `config` wins over the theme file.

Background `#191C22` @ 72% · Text `#ECEEF3` · Bold `#FFFFFF` · Cursor `#D97757` ·
Selection `#8A9BB8` @ 35% · Dim `#707888`

Slots sit at the sRGB primaries and secondaries — OKLCH red 29°, yellow 100°, green 142°,
cyan 195°, blue 262°, magenta 328° — all clearing 6.5:1. Dark only: blur turns the desktop
behind the window to gray mush, which a dark plate hides and a light plate reveals.

## Regenerate

```sh
osascript -l JavaScript make-theme.js
```

Edit the `themes` object; the profile is rewritten in place. Catches:

- Output path is hardcoded to `~/Workshop/liquid-glass-theme`
- `ghostty/liquid-glass-dark` is hand-maintained — the generator never touches it
- Terminal caches imported profiles; delete the old one before re-opening
- Terminal's AppleScript `background color` drops alpha silently — don't set glass with it
- Ghostty has no bold color and no selection alpha, so it carries composited `#3D4656`
- Blur units differ: Terminal `0.62` on 0–1, Ghostty `20` in pixels
